# State-Space Before Comparison

## A Standalone Framework for Relational State-Space Cartography, Degrees of Freedom, Composite Resolution, Comparability, and Transition Capability

---

# Status

This document extends Capability Cartography and Resolution Before Navigation.

Its purpose is to prevent a second common mistake:

```text
concepts are repeatedly treated as incomparable
because they do not belong to the same obvious category
```

The framework argues that:

```text
category sameness is not primary

scale sameness is not primary

surface similarity is not primary
```

The primary problem is:

```text
state-space adequacy
```

Before two objects can be compared:

```text
the map must contain dimensions capable of representing both
```

Before one object can transition into another:

```text
the map must contain relations capable of expanding, composing, transforming, or embedding the required state-space
```

---

# Abstract

Many frameworks treat comparison as if it requires objects of the same type.

They ask:

```text
Can a city be compared with a pedestrian?

Can a fish be compared with an AGI?

Can an electron be compared with a human?
```

and then answer too quickly:

```text
no
```

because the objects appear to occupy different categories or scales.

This document argues that this is usually the wrong failure mode.

The correct question is not:

```text
Are these the same kind of thing?
```

The prior question is:

```text
Which state-space dimensions, relations, and degrees of freedom are available for representing each?
```

Some comparisons are direct.

Some comparisons are partial.

Some comparisons require projection.

Some comparisons require decomposition.

Some comparisons require lifting into a richer state-space.

Some comparisons are undefined because the map lacks the required coordinates.

The framework therefore distinguishes:

```text
comparison

projection

embedding

decomposition

composition

transition

state-space expansion
```

and treats each as a different cartographic operation.

---

# 0. The Category Mistake

A category system asks:

```text
what kind of thing is this?
```

A state-space cartographer asks:

```text
what dimensions describe this?

what degrees of freedom does it possess?

what relations bind its components?

which projections make it comparable?

which embeddings make it representable?

which transitions make it reachable?
```

Two things can differ in category and still be comparable under some projection.

Example:

```text
electron

photon

quark
```

can be compared along dimensions such as:

```text
charge

mass-energy

spin

momentum

interaction type
```

But not every comparison coordinate applies equally.

For example:

```text
rest mass
```

applies differently to massive particles and massless particles.

The map must record this.

Comparison does not require identical categories.

It requires adequate coordinates.

---

# 1. Comparison Is Coordinate-Relative

A comparison is meaningful only relative to a coordinate system.

Given two objects:

```text
A

B
```

comparison requires at least one shared or mappable dimension:

```text
d(A)

d(B)
```

If the same dimension can be evaluated for both, comparison is direct.

Example:

```text
electron.mass

proton.mass
```

If the dimension applies to one object but not the other, comparison may be undefined.

Example:

```text
electron.voting_system
```

This is not false.

It is not zero.

It is not small.

It is undefined at that resolution.

The dimension does not exist in the electron's represented state-space.

---

# 2. Partial Comparability

Objects are rarely either fully comparable or fully incomparable.

They are usually partially comparable.

Example:

```text
electron

human
```

They can be compared along:

```text
mass

charge composition

energy

spatiotemporal location

physical interaction
```

But not directly along:

```text
language

memory

social identity

legal status

political preference
```

unless the electron is embedded into a larger composite structure where such dimensions emerge.

Therefore the map should not mark the comparison as simply:

```text
valid
```

or:

```text
invalid
```

It should mark:

```text
which dimensions compare

which dimensions project

which dimensions require lifting

which dimensions are undefined
```

---

# 3. Degrees Of Freedom

A degree of freedom is:

```text
a dimension along which a system can vary
while remaining representable as that system
```

An electron possesses limited degrees of freedom.

Examples:

```text
position

momentum

spin

charge

energy state
```

A molecule possesses more.

Examples:

```text
atomic composition

bond topology

bond angles

vibrational modes

rotational modes

conformation

reaction pathways

charge distribution
```

A cell possesses more again.

Examples:

```text
metabolic state

gene expression

membrane potential

internal transport

repair state

replication state

signaling state
```

A human possesses further layers.

Examples:

```text
physiology

memory

attention

language

goals

social relations

institutional position
```

More composite systems usually possess more degrees of freedom.

But this is not merely a matter of quantity.

New composites often introduce new kinds of coordinates.

---

# 4. Emergent Coordinates

Some dimensions are not visible at lower resolution.

They appear only after components are arranged in particular relations.

Examples:

```text
wetness
```

is not a coordinate of a single isolated hydrogen atom.

```text
metabolism
```

is not a coordinate of a single molecule.

```text
memory
```

is not a coordinate of a single neuron in the same way that it is a coordinate of a cognitive system.

```text
traffic
```

is not a coordinate of a single pedestrian.

```text
law
```

is not a coordinate of a single building.

These are emergent coordinates.

They require composites.

They require relations.

They require sufficient state-space.

The map should therefore distinguish:

```text
primitive dimensions

inherited dimensions

composite dimensions

emergent dimensions
```

---

# 5. Scale Is Not The Main Difference

Scale matters.

But scale alone is not the deepest issue.

Consider:

```text
electron

human
```

The difference is not merely:

```text
small

versus

large
```

The deeper difference is:

```text
few degrees of freedom

versus

many organized degrees of freedom
```

and:

```text
simple relation structure

versus

massively layered relation structure
```

A human is not just more matter.

A human is matter arranged through:

```text
atomic relations

molecular relations

cellular relations

tissue relations

organ relations

neural relations

social relations
```

The cartographic problem is therefore not merely scale translation.

It is relational and compositional expansion.

---

# 6. Decomposition And Composition Are Opposite But Not Symmetric

A human can be decomposed into electrons.

Example:

```text
human
↓
organs
↓
tissues
↓
cells
↓
molecules
↓
atoms
↓
electrons
```

This does not imply that a single electron can become a human.

The reverse operation requires additional matter, relations, constraints, energy flows, and assembly pathways.

The reverse path is not:

```text
electron
↓
human
```

It is closer to:

```text
many electrons
+
quarks
+
fields
+
nuclei
+
atoms
+
bonding relations
+
molecules
+
reaction networks
+
cells
+
developmental processes
+
ecological support
+
time
↓
human
```

Decomposition may be easy in one direction.

Composition may be difficult, constrained, or impossible in the other.

The map must not treat part-whole relations as reversible transformations.

---

# 7. Direct Transition Versus Mediated Transition

A direct transition exists when the source system already has sufficient state-space capacity and admissible dynamics to instantiate the target state.

Example:

```text
water.liquid
→
water.gas
```

under sufficient energy input.

A mediated transition requires intermediate state-space expansion.

Example:

```text
electron
→
human
```

is not direct.

It requires many intermediate layers:

```text
electron
→
atom-level participation
→
molecular participation
→
cellular participation
→
organism-level participation
→
human-level organization
```

The electron does not individually contain enough degrees of freedom to specify the human.

But electrons can participate in composites whose state-space supports humans.

This distinction matters.

The correct question is not only:

```text
can A become B?
```

but:

```text
can A directly become B?

can A participate in a composite that becomes B?

can A be transformed into a component of B?

can A be decomposed from B?

can B be assembled from many A-like components plus additional structure?
```

---

# 8. Relation Types

A capability map that only contains transition edges is too poor.

The map should distinguish relation types.

Examples:

```text
is-part-of
```

```text
contains
```

```text
composes-with
```

```text
decomposes-into
```

```text
transforms-into
```

```text
supports
```

```text
constrains
```

```text
embeds-into
```

```text
projects-onto
```

```text
inherits-dimension-from
```

```text
enables-emergent-coordinate
```

These should not be collapsed.

For example:

```text
human
→
electron
```

may be valid under decomposition.

But:

```text
electron
→
human
```

is not the same edge reversed.

It is a mediated composition pathway requiring additional supports.

---

# 9. Projection

Projection reduces a system to a smaller coordinate set.

Example:

```text
human
```

can be projected onto:

```text
mass
```

or:

```text
location
```

or:

```text
total charge
```

This allows comparison with simpler systems.

Example:

```text
human.mass

rock.mass

electron.mass
```

Projection makes heterogeneous comparison possible.

But projection loses structure.

If a human is projected only onto mass, then the map has discarded:

```text
biology

cognition

identity

agency

social position
```

The comparison is valid only for the projected dimension.

A map should record what was discarded.

---

# 10. Embedding

Embedding places a smaller state-space inside a richer one.

Example:

```text
electron
```

can be embedded into:

```text
atom
```

then:

```text
molecule
```

then:

```text
cell
```

then:

```text
organism
```

Embedding does not merely add size.

It adds relations.

An embedded electron participates in new constraints and new collective coordinates.

For example:

```text
electron in isolation
```

and:

```text
electron in a covalent bond
```

are not equivalent positions in capability space.

The same component can occupy different relational roles.

---

# 11. Equal Comparison

Equal comparison does not require identical objects.

It requires sufficient representational parity.

Two objects are equally comparable along a dimension when:

```text
the dimension is defined for both

the measurement operation is coherent for both

the comparison does not secretly change meaning between objects
```

Example:

```text
electron.charge

proton.charge
```

is a strong comparison.

Example:

```text
human.intelligence

AGI.intelligence
```

is weaker unless intelligence has first been decomposed into comparable dimensions.

Possible decompositions include:

```text
learning

planning

abstraction

memory

generalization

self-modeling

tool use

transfer across domains
```

Only after decomposition can comparison become disciplined.

The issue is not that humans and AGIs are incomparable.

The issue is that top-level labels are too compressed.

---

# 12. Composite Resolution

A composite concept must be decomposed before strong comparison.

Example:

```text
AGI
```

is not a coordinate.

It is a compressed region.

It may contain:

```text
perception

memory

reasoning

learning

planning

language

embodiment

self-correction

transfer

autonomy

world modeling

instrumental competence
```

Each component may itself require decomposition.

For example:

```text
reasoning
```

may decompose into:

```text
inference

abduction

deduction

counterfactual modeling

causal modeling

consistency maintenance

proof search

uncertainty management
```

Only when the relevant components are resolved can the map say coherently what AGI is in the context being analyzed.

The same applies to:

```text
fish

city

civilization

human

government

mind
```

Top-level concepts are often convenient handles for unresolved composites.

---

# 13. Berlin, Bike Lane, Pedestrian

Consider:

```text
Berlin

bike lane

pedestrian
```

These are not identical categories.

But they are comparable through a sufficiently rich state-space.

Berlin has dimensions such as:

```text
area

population

transport network

legal structure

infrastructure

energy use

traffic flow

institutional organization
```

A bike lane has dimensions such as:

```text
length

width

connectivity

surface quality

legal status

safety function

transport role
```

A pedestrian has dimensions such as:

```text
body position

walking speed

route preference

legal permissions

risk exposure

intention

perception
```

They can be compared along some dimensions:

```text
location

spatial extent

transport role

constraint participation

risk relation
```

They cannot be directly compared along others:

```text
population
```

is defined for Berlin but not for a bike lane in the same sense.

```text
walking speed
```

is defined for a pedestrian but not for Berlin in the same sense.

The map should therefore represent:

```text
shared dimensions

role relations

containment relations

support relations

constraint relations

undefined dimensions
```

Berlin contains bike lanes.

Bike lanes support pedestrian and cyclist routing constraints.

Pedestrians occupy and traverse Berlin.

The comparison is valid only when the relation type is made explicit.

---

# 14. AGI And Fish

Consider:

```text
AGI

fish
```

A naive category system may say:

```text
incomparable
```

A state-space map asks:

```text
which dimensions are shared?

which dimensions differ?

which dimensions require decomposition?
```

Possible shared dimensions:

```text
perception

control

adaptation

learning

energy/resource dependence

environmental coupling

survival or persistence constraints

information processing
```

Possible fish-specific dimensions:

```text
metabolism

body morphology

aquatic locomotion

reproduction

immune function
```

Possible AGI-specific dimensions:

```text
model architecture

training process

computational substrate

symbolic or latent representation

self-modification capacity

deployment environment
```

The comparison is not globally invalid.

It is coordinate-dependent.

A fish and an AGI may be compared as adaptive information-processing systems.

They may not be directly compared as biological organisms unless the AGI has biological embodiment or the coordinate is lifted to a more abstract class.

---

# 15. State-Space Capacity

A system can only instantiate states that its state-space can support.

Example:

```text
a single electron
```

cannot instantiate:

```text
language
```

not because language is magical,

but because language requires:

```text
memory

symbols or representations

state persistence

compositional structure

communication channels

interpretive relations

learning history
```

These are not available in the state-space of a single electron.

They require a larger organized system.

The absence is structural.

Not merely categorical.

---

# 16. Supports Expand State-Space

Supports can expand the effective state-space of a system.

Example:

```text
human
+
writing system
```

supports memory and coordination states unavailable to an unaided individual.

Example:

```text
human
+
computer
+
internet
```

supports search, computation, communication, and coordination states unavailable to the biological organism alone.

Example:

```text
city
+
transport network
```

supports reachable movement states unavailable to disconnected settlements.

Supports do not merely make paths easier.

They can create new reachable regions of state-space.

This connects state-space cartography to capability cartography.

A support is a structure that changes what states or transitions are admissible.

---

# 17. Admissibility Depends On State-Space

A transition is admissible only if the source, supports, and environment jointly provide enough structure for the target.

Given:

```text
source A

target B
```

ask:

```text
Does A contain the required degrees of freedom?

If not, can supports supply them?

If not, can A be embedded into a composite that supplies them?

If not, can intermediate transitions construct them?

If not, is the transition blocked?
```

This prevents two errors.

First error:

```text
assuming transition is impossible because A alone is insufficient
```

Second error:

```text
assuming transition is possible because B is imaginable
```

The map must resolve the required state-space path.

---

# 18. Compositional Reachability

Compositional reachability asks:

```text
can the target be assembled from available components under admissible relations?
```

This differs from ordinary reachability.

Ordinary reachability:

```text
A
→
B
```

Compositional reachability:

```text
A1 + A2 + A3 + ... + relations + supports
→
B
```

Example:

```text
one brick
→
house
```

is not direct.

But:

```text
many bricks
+
wood
+
steel
+
labor
+
design
+
land
+
permissions
+
time
→
house
```

may be admissible.

The same structure applies to:

```text
molecules
→
organism
```

```text
humans
→
institution
```

```text
compute units
→
AGI
```

The target is not reached by one component alone.

It is reached by organized composition.

---

# 19. Resolution Of “From”

The phrase:

```text
from A to B
```

is often ambiguous.

It may mean:

```text
A transforms into B
```

or:

```text
A is used as a component of B
```

or:

```text
many instances of A compose B
```

or:

```text
A is decomposed from B
```

or:

```text
A enables B
```

or:

```text
A supports a transition to B
```

or:

```text
A and B are compared under a shared projection
```

Therefore every transition claim must resolve the meaning of:

```text
from
```

before the map can determine admissibility.

---

# 20. State-Space Lifting

State-space lifting occurs when comparison or transition requires moving to a richer representation.

Example:

```text
electron

human
```

At the particle-coordinate level, comparison is possible but thin.

At the biological-coordinate level, the electron cannot be represented as a human-like system.

To relate them, the map must lift through intermediate spaces:

```text
particle space
↓
atomic space
↓
molecular space
↓
biochemical space
↓
cellular space
↓
organismic space
↓
cognitive/social space
```

Each lift introduces new dimensions and new admissibility constraints.

A lift is not a route by itself.

It is an expansion of representational capacity.

---

# 21. State-Space Compression

State-space compression occurs when a complex object is represented in fewer dimensions.

Example:

```text
human
```

compressed to:

```text
mass
```

or:

```text
location
```

or:

```text
agent
```

Compression is useful.

But it can hide decisive structure.

For example:

```text
AGI
```

compressed to:

```text
smart machine
```

may be too low-resolution for admissibility analysis.

```text
city
```

compressed to:

```text
large settlement
```

may be too low-resolution for infrastructure analysis.

Compression enables handling.

Decompression enables fidelity.

Both are cartographic operations.

---

# 22. False Equivalence

False equivalence occurs when two objects are compared under a coordinate that appears shared but changes meaning across cases.

Example:

```text
intelligence of a fish

intelligence of an AGI
```

may be coherent under some decompositions and incoherent under others.

If intelligence means:

```text
adaptive control under environmental uncertainty
```

then comparison may be possible.

If intelligence means:

```text
human-like verbal reasoning
```

then the comparison becomes narrower and excludes many fish-relevant capacities.

The map must record the operative decomposition.

Otherwise comparison becomes rhetorical rather than cartographic.

---

# 23. False Incomparability

False incomparability occurs when two objects are declared incomparable because they differ in category or scale, even though valid projections or embeddings exist.

Example:

```text
city

organism
```

may be compared along:

```text
energy throughput

transport networks

repair processes

information flow

boundary maintenance

internal specialization
```

This does not mean:

```text
city = organism
```

It means:

```text
some dimensions admit comparison
```

A good map avoids both errors:

```text
false equivalence

false incomparability
```

---

# 24. The Comparability Ladder

The framework proposes a ladder of increasing comparison strength:

```text
no represented relation

↓

shared projection

↓

shared dimension

↓

shared decomposed substructure

↓

shared dynamics

↓

shared generative process

↓

mutual embedding

↓

direct transformability
```

Each level supports stronger claims than the level before it.

For example:

```text
electron and human
```

share physical projections.

They do not share direct transformability.

```text
fish and human
```

share biological substructure and evolutionary history.

They do not share all cognitive or social dimensions.

```text
human and AGI
```

may share functional projections.

They may not share substrate, development, embodiment, or biological dynamics.

The ladder prevents flat comparison.

---

# 25. The Transition Ladder

The framework also proposes a ladder of transition strength:

```text
projection only

↓

component participation

↓

composition with many instances

↓

composition with heterogeneous supports

↓

mediated transformation

↓

direct transformation

↓

reversible transformation
```

Example:

```text
electron → human
```

may be possible only through component participation and massive mediated composition.

Example:

```text
ice → water
```

is a direct physical transformation.

Example:

```text
water ↔ ice
```

is approximately reversible under ordinary conditions.

The map should not collapse all of these into:

```text
reachable
```

because the structure of reachability differs.

---

# 26. Map Fidelity Requires Relation Fidelity

A low-fidelity map records:

```text
A relates to B
```

A higher-fidelity map records:

```text
A compares with B along dimension d
```

or:

```text
A decomposes into B
```

or:

```text
A can be embedded into C where B becomes reachable
```

or:

```text
A supports B but does not become B
```

or:

```text
A and B share a projection but not a generative process
```

Relation fidelity is as important as node fidelity.

Without relation fidelity, the map confuses:

```text
part-whole

cause-effect

support

transition

analogy

identity

projection

embedding
```

and therefore produces invalid navigation.

# 27. The State-Space Hierarchy

The framework proposes:

```text
distinction formation

↓

state-space identification

↓

degree-of-freedom analysis

↓

relation typing

↓

projection analysis

↓

embedding analysis

↓

composite decomposition

↓

emergent coordinate discovery

↓

state-space adequacy judgment

↓

comparability analysis

↓

transition capability analysis

↓

reachability analysis

↓

navigation

↓

optimization
```

This does not replace Resolution Before Navigation.

It refines the earlier layers.

Before asking whether a destination is reachable, the map must determine whether the source and destination are even represented in compatible, projectable, or liftable state-spaces.

---

# 28. Consequences For Capability Cartography

Capability is not merely:

```text
having a route
```

Capability requires:

```text
state-space sufficient to represent the target

relations sufficient to support the target

dynamics sufficient to reach the target

constraints permissive enough to admit the target
```

A system lacking the necessary state-space cannot directly reach the target.

But it may still:

```text
acquire supports

compose with other systems

embed into larger structures

construct intermediate layers

increase its degrees of freedom
```

Capability growth is therefore partly:

```text
state-space expansion
```

A system becomes more capable when it can represent, vary, preserve, and navigate more dimensions of reality.

---

# 29. Intelligence As State-Space Expansion

Intelligence can be viewed as the ability to:

```text
form distinctions

identify relevant dimensions

decompose composites

select projections

construct embeddings

track relations

resolve state-space adequacy

discover admissible transitions

navigate expanded possibility regions
```

A weak system compares only surface labels.

A stronger system compares projected dimensions.

A still stronger system resolves hidden structures.

A more general system can move between many state-spaces without confusing their coordinates.

Generality is not merely solving many tasks.

Generality is broad competence in translating, lifting, compressing, comparing, and navigating across heterogeneous state-spaces.

---

# 30. Final Compression

A category system asks:

```text
Are these the same kind of thing?
```

A state-space cartographer asks:

```text
Which dimensions represent each?

Which degrees of freedom exist?

Which relations bind the parts?

Which projections are shared?

Which embeddings are possible?

Which coordinates emerge only in composites?

Which comparisons are direct?

Which comparisons are partial?

Which comparisons are undefined?

Which transitions are direct?

Which transitions require mediation?

Which transitions require composition?

Which supports expand the reachable state-space?
```

An electron and a photon can be compared directly along some physical dimensions.

An electron and a human can be compared thinly by projection, but not richly without lifting through many compositional layers.

A human can yield an electron by decomposition.

An electron cannot yield a human by simple reversal.

It can only participate in larger admissible compositions that possess enough degrees of freedom and relation structure for human-level states.

Therefore:

```text
comparison is downstream of state-space adequacy

transition is downstream of compositional support

navigation is downstream of relation fidelity

optimization is downstream of navigation
```

The map does not forbid comparison across scale.

It forbids pretending that all comparisons occur in the same coordinate system.

The task is not to decide whether things are comparable in general.

The task is to resolve the state-space in which comparison becomes meaningful.
