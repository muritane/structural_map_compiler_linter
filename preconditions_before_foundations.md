# Preconditions Before Foundations

## A Standalone Framework for Structural Necessity, Reality Constraints, Invariance Support, Correspondence Support, Admissibility, and the Search for Minimal Preconditions

---

# Status

This document is standalone.

It does not begin with objects.

It does not begin with laws.

It does not begin with information.

It does not begin with computation.

It does not begin with identity.

It does not begin with truth.

It begins with a different question:

```text
What must reality not lack
before any recognizable structure can exist?
```

The proposal is:

```text
many foundational searches begin incorrectly.
```

They ask:

```text
What is fundamental?
```

before asking:

```text
What is required?
```

This framework reverses the direction.

Instead of searching for the ultimate thing,

it searches for the minimal preconditions.

---

# Abstract

Many frameworks seek foundations.

Examples:

```text
particles

fields

objects

laws

information

computation

mathematics

consciousness
```

The search proceeds by asking:

```text
Which of these is most fundamental?
```

This framework proposes a different strategy.

Before asking what reality is made of, ask:

```text
What must reality permit?
```

The existence of:

```text
identity

measurement

memory

language

computation

invariants

observers

knowledge
```

places constraints on what reality can be like.

A reality that lacks the necessary preconditions cannot support these phenomena.

The framework therefore seeks:

```text
minimal necessity

not maximal ontology
```

In compressed form:

> Before asking what reality is, ask what reality must be capable of supporting.

---

# 0. The Foundational Reversal

Most foundational projects proceed as follows:

```text
candidate primitive
    ->
explain everything else
```

Examples:

```text
matter

energy

information

fields

relations

processes
```

The hope is:

```text
find the correct primitive
```

and the rest follows.

However a recurring problem appears.

Every candidate foundation seems to require prior structure.

Objects require organization.

Organization requires admissible transformations.

Transformations require distinctions.

Distinctions require persistence.

Persistence requires recoverability.

Recoverability requires preserved distinction.

The candidates repeatedly depend upon one another.

The search for foundations begins to resemble an infinite regress.

---

# 1. Preconditions Versus Foundations

A foundation answers:

```text
What is everything made of?
```

A precondition answers:

```text
What must already be possible?
```

These are not the same question.

For example:

Suppose language exists.

The framework does not ask:

```text
What substance is language made of?
```

It asks:

```text
What must reality support
before language can exist?
```

The answer includes:

```text
persistent distinctions

recognition

memory

reproduction

error tolerance

recoverability
```

Language is evidence that these capacities exist.

The framework therefore shifts from:

```text
substance seeking
```

to:

```text
precondition seeking
```

---

# 2. The Elimination Principle

A useful strategy is:

```text
start with an observed capability

identify what realities cannot support it

eliminate them
```

For example:

If computation exists:

```text
reality cannot forbid
stable transformation structure
```

If identity exists:

```text
reality cannot destroy
all persistence
```

If communication exists:

```text
reality cannot destroy
all recoverable distinctions
```

If invariants exist:

```text
reality cannot be universally
invariance-hostile
```

The framework therefore progresses through exclusion.

Not:

```text
This is reality.
```

but:

```text
Reality cannot lack this.
```

---

# 3. The Strong Constraint View

Consider two universes.

Universe A:

```text
patterns persist

distinctions survive

memory forms

organization recovers
```

Universe B:

```text
all distinctions immediately collapse

all patterns instantly dissolve

nothing remains identifiable
```

Universe B cannot contain:

```text
language

measurement

identity

knowledge

science

observers
```

The issue is not intelligence.

The issue is structural possibility.

Thus:

> Some realities are excluded by the existence of recognizable structure itself.

---

# 4. Invariants as Constraint Witnesses

Traditional language says:

```text
reality contains invariants
```

This framework proposes:

```text
invariants witness support
```

An invariant is evidence that reality permits preservation across admissible variation.

The invariant is not the deepest object.

The invariant is a clue.

It points toward a deeper necessity:

```text
reality must permit invariance
```

before any invariant can exist.

Thus:

> Invariants are witnesses of possibility conditions.

---

# 5. Correspondence as Constraint Witness

Likewise:

```text
knowledge exists

measurement exists

navigation exists
```

These are not merely epistemic achievements.

They imply something about reality.

If correspondence repeatedly succeeds:

```text
reality must permit
recoverable alignment
```

Otherwise:

```text
maps cannot remain useful

measurements cannot remain calibrated

knowledge cannot accumulate
```

Correspondence therefore functions as evidence that reality is not completely correspondence-hostile.

---

# 6. Admissibility Before Objects

Many explanations begin with things.

This framework begins with possibility.

The relevant question becomes:

```text
What transformations are admissible?
```

rather than:

```text
What objects exist?
```

An object is then understood as:

```text
a stable organization
supported by admissible transformations
```

rather than:

```text
a primitive thing
```

Objects become consequences.

Not starting points.

---

# 7. The Failure of Ultimate Nouns

A recurring pattern appears.

Whenever a candidate foundation is proposed:

```text
object

law

information

identity

computation

observer
```

one can ask:

```text
What must already be true
before this can exist?
```

The search repeatedly moves downward.

Not toward smaller objects.

But toward more general preconditions.

This suggests that reality may resist explanation in terms of ultimate nouns.

---

# 8. Minimal Preconditions

The framework does not claim these are final.

But recurring candidates appear.

Reality must possess enough structure to support:

```text
distinction

persistence

admissible transformation

recoverability

preserved organization

invariance support

correspondence support
```

Remove enough of these and:

```text
identity collapses

measurement collapses

language collapses

computation collapses

knowledge collapses
```

The exact list may evolve.

The method remains the same.

Ask:

```text
Without X,
what becomes impossible?
```

---

# 9. Why This Is Not Ontology

The framework does not claim:

```text
distinction is reality

or

persistence is reality

or

admissibility is reality
```

Instead it claims:

```text
any reality supporting
recognizable structure
must not lack them
```

This is a weaker claim.

But it is also more difficult to refute.

The framework therefore avoids premature commitments regarding:

```text
ultimate substance

ultimate ontology

final metaphysics
```

while still generating strong constraints.

---

# 10. Reality Through Necessary Support

The traditional path is:

```text
find the foundation

derive the world
```

This framework proposes:

```text
observe the world

identify what it requires

eliminate realities
that cannot support it
```

The direction is reversed.

Reality is approached through necessity.

Not declaration.

---

# Final Compression

The traditional question is:

```text
What is fundamental?
```

The proposed question is:

```text
What must reality not lack?
```

Not:

```text
What is the ultimate thing?
```

but:

```text
What must already be possible
before any thing can persist,
be recognized,
be measured,
be communicated,
or be known?
```

And therefore:

> The search for foundations may be less productive than the search for minimal preconditions.

> Reality may be approached more reliably through necessity than through primitive declarations.

> The existence of recognizable structure constrains what reality can be.

> Before asking what reality is made of, ask what reality must be capable of supporting.
